Google Maps API key

Align-on-map uses the Maps JavaScript API. Create a key in Google Cloud, enable Maps JavaScript API, and restrict it to http://localhost:*. Serve this folder with python3 -m http.server and open http://localhost:8000/map-graph-digitizer.html — file:// usually will not load the map.

The key is stored only in this browser.

Tips
Mouse wheel — zoom in/out
Right-click drag (or hold Space + drag) — pan
Click — place / snap a node, chain an edge
Ctrl/Cmd + click — inspect: highlight on the map and jump to the row in the list
Delete — turn on Delete, then click a node or edge to remove it (also Alt+click, or the × in the list, or the Delete key). Undo restores it. Removing an arrow also drops unused endpoints.
Placing a node on top of existing line(s) — splits each edge at the junction
Esc — end chain / clear inspect / clear edge selection
Ctrl/Cmd + Z — undo
Double-click — rename node or edge
Shift + click edges — multi-select, then name them and set type (road / rail / water / border)
New edge type in the toolbar applies to the next edges you draw
Map / Nodes / Edges / Labels — hide the photo to review only the vector drawing. Uncheck a type (road / rail / water / border / arrow) to hide those edges. Bg sets the canvas behind the drawing: standard, white, grey, or black.
Sketch — drag to draw temporary notes (blue / black / red). Never saved. Ctrl+Z undoes the last stroke while Sketch is on.
Add arrow — two clicks: first is the start, second is the end. Snaps to a node or onto a street without splitting it, or drops a free endpoint. Grey / black / blue. Esc cancels the start. Does not chain streets.
Numeral — pick 1–69 to tint likely neighborhoods in 25% red, based on numbers already placed (nearby values and the same decade, e.g. 61–65). Place more numbered markers to tighten the guess. Clear removes the tint.
