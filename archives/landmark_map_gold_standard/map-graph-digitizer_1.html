Google Maps API key

Align-on-map uses the Maps JavaScript API. Create a key in Google Cloud, enable Maps JavaScript API, and restrict it to http://localhost:*. Serve this folder with python3 -m http.server and open http://localhost:8000/map-graph-digitizer.html — file:// usually will not load the map.

The key is stored only in this browser.

Tips
Mouse wheel — zoom in/out
Right-click drag (or hold Space + drag) — pan
Click — place / snap a node, chain an edge
Ctrl/Cmd + click — inspect: highlight on the map and jump to the row in the list
Delete — turn on Delete, then click a node or edge to remove it (also Alt+click, or the × in the list, or the Delete key). Undo restores it. Removing an arrow also drops unused endpoints.
Placing a node on top of existing line(s) — splits each edge at the junction
Esc — end chain / clear inspect / clear edge selection
Ctrl/Cmd + Z — undo
Double-click — rename node or edge
Shift + click edges — multi-select, then name them and set type (road / rail / water / border)
New edge type in the toolbar applies to the next edges you draw
Map / Nodes / Edges — hide the photo to review only the vector drawing. Labels has four modes: all, only_streets (edge names), only_non_streets (node names) or off. Uncheck a type (road / rail / water / border / arrow) to hide those edges. Bg sets the canvas behind the drawing: standard, white, grey, or black.
Sketch — drag to draw temporary notes (blue / black / red). Never saved. Ctrl+Z undoes the last stroke while Sketch is on.
Add arrow — two clicks: first is the start, second is the end. Snaps to a node or onto a street without splitting it, or drops a free endpoint. Grey / black / blue. Esc cancels the start. Does not chain streets.
Numeral — pick 1–69 to tint likely neighborhoods in 25% red, based on numbers already placed (nearby values and the same decade, e.g. 61–65). Place more numbered markers to tighten the guess. Clear removes the tint.

1. Click a node in the top pane (or a row in the list, or press N for the next unplaced one).
2. Click its true location in the bottom pane. The dashed ring shows where the current model expects it.
3. Repeat. The graph on the bottom pane re-warps on every click or drag.
Drag a green/amber/red marker in the bottom pane to refine it. Del removes the selected GCP, Ctrl/Cmd+Z undoes.
Pan left-drag or right-drag, zoom wheel (each pane independent).
Colours — error relative to the RMSE: green ≤1.25×, amber ≤2.5×, red beyond. Red lines join each marker to where the model puts it.
Methods — Linear: X=a+b·x, Y=c+d·y (≥2 pts). Poly 1 = affine (≥3). Poly 2 (≥6), Poly 3 (≥10) are least-squares fits. Thin plate spline (≥3) passes through every GCP, so its error is leave-one-out: each GCP is predicted from all the others.
Add raster / GeoTIFF — opens an import dialog: pick a max size (default 2048 px) and compression quality. The file is read from its smallest suitable overview, reprojected to Web Mercator (this also removes UTM grid convergence) and compressed, so pan/zoom stays real-time. R toggles all rasters; the slider sets their opacity.
Full screen (or F) — hides the sidebar and toolbar so only the two panes remain; controls sit in a slim strip you can hide with H. Press F again or use Exit to return.
Apply to nodes writes lon/lat (pinned nodes keep their exact position); then use Align on map for export or fine tuning.
